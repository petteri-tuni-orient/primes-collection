Both buttons use shared/primes.js. The browser calls the function directly; the server button sends an HTTP request to Express, which runs that function in Node.js.

Calculation time measures the function call. Total request time also includes communication and response handling. Small calculations can finish in less than a millisecond; timings vary between runs. Larger browser calculations may briefly pause the page.
